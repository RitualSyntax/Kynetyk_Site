v0.2.3Update18 Nov 2026

Black icon

  • App icon now has a black background, to match the rest of the KYNETYK apps
v0.2.2Update18 Nov 2026

New icon

  • New app icon: the Grid mark, the dot-matrix clip grid with the red square as the live clip
v0.2.1Update18 Nov 2026

Always live

  • The Go live button is gone. vyz is always live
  • Outputs set to Open automatically open as soon as a set loads, or as soon as you add one. You can still open and close any output by hand in Output setup
  • Quitting asks first only while outputs are open
v0.2.0Major update18 Nov 2026

Virtual outputs

  • New output type: Virtual (Windows). There's no window; the picture goes straight to other apps over Spout, so mapp, lynk, Resolume, TouchDesigner and anything else with Spout can pick it up
  • Add one in Output setup › Add output › Virtual output. It shows up as "KYNETYK vyz" plus the output's name
  • Virtual outputs start when you go live, the same as window outputs
  • vyz now shows up in lynk with its virtual outputs, ready to patch into mapp
v0.1.1First release17 Nov 2026

vyz is out

  • Clip grid with layers as rows, banks, groups and an A/B group crossfade
  • Video, images, cameras, generators and ISF shaders
  • 22 effects with envelopes on every setting
  • Free, beat sync and timecode playback
  • Window outputs cut into layered slices, and recording to file
  • MIDI and OSC learn, Launchpad and APC presets, MIDI clock in, MTC out and a phone remote

Bug fix
Fixes for things that didn't work as they should.
Hotfix
An urgent fix, out soon after a release.
